# 从单用户版本升级到账号版本

适用环境：Windows、Python 3.13、MySQL 8.0；已有 001—004 数据库迁移。
本次新增用户名登录与账号隔离，不需要购买短信服务、域名或新的 Python 依赖。
AI 仍使用服务器配置的 API Key，认证限流不等于 AI 调用限额。

## 1. 停止服务并备份

在启动 uvicorn 的终端按 Ctrl+C。升级期间不要同时运行旧服务。
在 Navicat 中选中 lesslab 数据库，导出 SQL 文件，包含“结构和数据”，
保存在项目目录之外。确认导出的文件包含 resources、study_plans、current_goal、
study_plan_progress 的建表语句和已有记录。
代码备份不包含数据库；GitHub 不会备份收藏内容。

## 2. 更新代码、运行离线测试

若通过升级包更新，将包内的文件按相对路径覆盖到项目目录。
保留原有 .env、.venv、.git 和未涉及的文件；不要把更新包当成完整项目删除重建。
若助手已经完成代码安装，跳过复制步骤。

在 VS Code 终端执行：

```powershell
cd D:\codex\lesslab
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

预期：Ran 106 tests / OK。这一步不访问真实数据库或模型。

## 3. 执行 005 数据库迁移

在 Navicat 使用有建表和改表权限的管理员连接打开查询，
打开项目的 migrations/005_add_accounts.sql，执行整份脚本一次。
不要重新执行 init.sql 或已经执行过的 001—004。

005 新建账号、会话等表，并给收藏、计划增加 owner_id 字段。
不会删除原有收藏或计划。此时旧数据还没有主人，网页账号暂时看不到它们。

MySQL 建表和改表可能逐条生效。如果报错，请保留错误信息，停止后续步骤，
先检查已生效的表和字段；不要重复执行整份脚本，也不要删除旧表重建。
本次离线测试不能代替这里的真实 MySQL 验证。

## 4. 创建自己的初始账号

继续在 VS Code 终端执行：

```powershell
.\.venv\Scripts\python.exe setup_owner.py
```

按提示输入用户名和两次密码：

- 用户名：3—32 位英文字母、数字或下划线，大小写视为同一个用户名。
- 密码：15—128 个字符。可以使用较长的易记短语；输入时没有星号或文字是正常的。
- 这是网站登录密码，与 MySQL 数据库密码是两回事。不要发到聊天中。

脚本会在一个事务中创建账号，将原收藏、计划和当前目标归属这个账号。
计划编号、历史快照、完成进度保留。重复运行会拒绝再次初始化。
只有看到“初始账号创建成功”才继续启动网页。

如果提示数据库权限不足，应用账号需要对 lesslab.* 拥有
SELECT、INSERT、UPDATE、DELETE 权限；建表改表仍由管理员完成。

## 5. 启动并检查

```powershell
.\.venv\Scripts\python.exe -m uvicorn main:app --reload
```

访问 http://127.0.0.1:8000/ ，会进入登录页。
用第 4 步设置的账号登录，确认旧收藏、目标、计划历史和完成进度仍在。
修改一条收藏状态后刷新确认保存，退出后再次访问首页，应回到登录页。
这些操作不需要调用 AI。

已有 .env 不需要覆盖。新增配置未填写时会使用以下本机默认值：

```dotenv
APP_ORIGIN=http://127.0.0.1:8000
AUTH_COOKIE_SECURE=false
AUTH_ALLOW_REGISTRATION=false
```

浏览器地址须与 APP_ORIGIN 一致；不要换成 localhost 或其他端口。
注册默认关闭，主账号由本机脚本创建。

## 6. 可选：验证第二个账号

只在本机运行时，在 .env 增加 AUTH_ALLOW_REGISTRATION=true，停止并重启服务。
退出当前账号，点击登录页“创建一个新账号”，用另一用户名和新密码注册。
注册成功后登录，应看到空收藏、空计划和未设置的目标；无法读取原主账号资料。
测试完成后改回 false 并重启；已有账号仍能登录。

会话有效 8 小时。认证接口有登录/注册次数限制，测试过多会暂时返回 429，
等待窗口结束即可。当前没有找回密码或修改密码页面，请自行妥善保存密码。

代码与界面已做离线验证；真实 MySQL 的 005 执行、旧数据归属和并发行为还需验收。

不提交 .env、数据库备份、虚拟环境、测试账号密码或本地备份文件。

AI 调用限额、新建收藏/计划的防重复机制、HTTPS 与部署验证仍未完成。

## 出错时恢复

仅复制代码之前的备份不能撤销数据库迁移。
若需要完整回退，先停止服务，再由数据库管理员恢复第 1 步的完整数据库备份，
配套恢复升级前代码。不要让旧代码连接已迁移且已有多个账号的数据库：
旧代码没有账号过滤，会混合展示不同账号的数据。
遇到错误先保留报错并定位，避免未经确认覆盖升级后新产生的数据。
