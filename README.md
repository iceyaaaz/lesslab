# 留白 LessLab

把收藏，变成行动。

一个使用 Python、FastAPI 和 MySQL 开发的学习收藏管理项目，
支持收藏管理、学习状态记录、按时间安排任务，以及结合学习目标生成 AI 计划。

## 当前开发状态

已实现用户名登录、退出和按账号隔离数据，并保留收藏管理、归档恢复、当前目标、
规则计划、AI 计划、计划历史与任务完成进度。默认关闭公开注册。

2026-09-30：106 项离线测试通过；隔离预览环境验证了登录、收藏状态保存、退出和
切换账号后的数据隔离。项目维护者已在本机执行 005 迁移并反馈账号功能可用；
真实 MySQL 并发验证和外部访问验收尚未完成。

当前版本作为开源学习与求职作品，暂不扩展功能。AI 调用限额、保存防重复和
外部访问验收列为可选后续工作，不作为本次源码发布的前置条件。

## 已实现功能

- 账号：用户名与密码注册（需开启）、登录、退出及会话过期。
- 数据隔离：后端按当前账号筛选收藏、目标、计划、进度与 AI 候选资料。
- 旧数据迁移：由本机初始化脚本创建的主账号接收旧数据，不由首个网页注册用户领取。

- 计划执行：在历史详情中勾选任务，保存完成进度，支持改回未完成。
- 当前目标：保存目标、验收标准、目标日期和默认时长，可带入 AI 计划。
- 新增收藏：记录标题、链接和预计学习时长。
- 查看收藏：展示收藏卡片，打开原文。
- 状态管理：标记已完成，或改回待学习。
- 归档与恢复：归档后不再参与新计划，恢复时保留原学习状态。
- 计划历史：保存 AI 计划并查看保存时的资料快照，无需再次调用模型。
- 标题搜索：支持关键词匹配，忽略英文大小写。
- 状态筛选：查看全部、待学习或已完成的收藏。
- 快速计划：按时长从短到长安排待学习内容，无需调用模型。
- AI 计划：依据目标选择收藏，显示推荐理由与本次 token 用量。
- 结果校验：检查模型返回结构、收藏编号、重复项和时间预算。

## 快速计划规则

目前使用固定规则生成计划：

1. 只选择未归档、待学习、已填写有效时长的收藏。
2. 优先安排耗时短的内容；时长相同时优先选择编号小的收藏。
3. 累计预计时长不超过用户输入的时间预算。

快速计划不调用大模型。该规则优先安排短任务，不保证把时间预算填得最满。

## AI 学习计划

配置 DeepSeek API 后，可以输入学习目标和时间预算生成 AI 建议。

1. 后端读取当前账号最近最多 20 条符合时间条件且未归档的待学习收藏。
2. 将目标、候选收藏的编号、标题和预计时长发送给 DeepSeek。
3. 模型最多选择 8 项内容，并提供基于标题的推荐理由。
4. Python 校验返回结构、编号、重复项与总时长；不合格的计划会被拒绝。
5. 网页展示通过校验的计划和模型返回的 token 用量。

项目不自动读取链接正文，学习时长由用户填写。
没有候选收藏时不调用模型；每次生成请求最多调用模型一次，不自动重试。
模型超时或输出不合格时会显示错误，用户仍可主动使用独立的快速计划入口。

模型调用按配置的 API Key 所属账户计费。生成失败不一定代表没有产生用量，
实际费用以模型平台记录为准。当前尚未实现账户限额或全站预算控制。

## 本地启动（Windows PowerShell）

### 1. 准备环境

安装 Python 3.13 和 MySQL 8.0，确保 MySQL 服务正在运行。

下载项目后，在 VS Code 中打开项目文件夹。
下面的终端命令均在项目根目录执行。

### 2. 安装 Python 依赖

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

### 3. 初始化数据库

在 Navicat 中使用拥有建库、建表权限的管理员连接，
首次安装按顺序执行：

1. `init.sql`
2. `migrations/001_create_study_plans.sql`
3. `migrations/002_add_resource_archive.sql`
4. `migrations/003_create_current_goal.sql`
5. `migrations/004_create_plan_progress.sql`
6. `migrations/005_add_accounts.sql`

已有数据库只执行尚未应用的迁移。002 添加 `resources.archived_at` 字段，
只执行一次；可先运行 `SHOW COLUMNS FROM lesslab.resources LIKE 'archived_at';` 检查。
升级期间先停止服务并备份数据库，完成迁移与代码更新后再启动。
005 只执行一次；MySQL 建表/改表不能通过一个事务撤销整份脚本。
若中途报错，先检查已创建的表和字段，不要直接重跑或删除原表。
已有项目升级详见 [登录升级说明](docs/login-upgrade.md)。

随后在管理员查询窗口中创建应用专用账号。
执行前，将下面的密码占位文字换成自己设置的密码。
不要把实际密码写回本说明文件或提交到 Git。

```sql
CREATE USER 'lesslab_app'@'127.0.0.1'
IDENTIFIED BY 'replace_with_your_password';

GRANT SELECT, INSERT, UPDATE, DELETE
ON lesslab.*
TO 'lesslab_app'@'127.0.0.1';
```

以上创建账号的语句用于首次安装。
如果账号已经存在，请使用该账号已有的配置，不要重复创建。

### 4. 配置环境变量

首次安装且没有 `.env` 时，复制模板：

```powershell
Copy-Item .env.example .env
```

编辑 `.env`，填写实际数据库地址、端口、账号和密码。

已有 `.env` 时不要覆盖。数据库密码只保存在本地配置中。

### 5. 配置 AI（可选）

如果需要 AI 计划，在本地 `.env` 中填写：

```dotenv
DEEPSEEK_API_KEY=your_api_key_here
DEEPSEEK_BASE_URL=https://api.deepseek.com
DEEPSEEK_MODEL=deepseek-flash
```

真实密钥只放在 `.env`，不要放入网页或提交到 Git。
不配置密钥时仍可使用收藏管理与快速计划，AI 接口会提示未配置。

可选连接测试（会发送一次真实请求，可能产生费用）：

```powershell
.\.venv\Scripts\python.exe check_deepseek.py
```

模型名称和计费方式以 [DeepSeek 官方文档](https://api-docs.deepseek.com/zh-cn/)为准。

### 6. 创建本机初始账号

完成 005 后，在自己的终端执行一次：

```powershell
.\.venv\Scripts\python.exe setup_owner.py
```

按提示设置用户名（3—32 位字母、数字或下划线）和密码（15—128 个字符）。
密码输入时不会显示。不要将密码发到聊天或放入 Git。
脚本在一个事务中创建账号、接收旧收藏和计划、复制旧目标；原计划编号与执行进度保留。
未初始化前，网页无法注册；已有主账号时脚本拒绝重复初始化。

### 7. 启动服务

```powershell
.\.venv\Scripts\python.exe -m uvicorn main:app --reload
```

浏览器访问：

- 登录：http://127.0.0.1:8000/login
- 首页：http://127.0.0.1:8000/（未登录会跳到登录页）
- 接口文档：http://127.0.0.1:8000/docs
- 数据库连接检查：http://127.0.0.1:8000/health/db（须先登录）

停止服务：在运行服务的终端按 Ctrl+C。

不访问 MySQL，不调用 DeepSeek，也不消耗模型额度。

当前共 106 项离线测试，覆盖：

- 未登录拦截、跨账号越权、会话过期/退出、CSRF、登录限流、密码校验和旧数据归属。

- AI 计划结构、编号、重复项、预算边界、超时与异常响应。
- 历史计划保存时的数据校验和快照保留。
- 归档恢复，以及新计划排除已归档资料。
- 当前目标的字段校验与版本冲突处理。

这些测试不替代真实 MySQL 集成测试、页面测试或推荐质量评估。
SQLite 测试适配器不模拟 MySQL 行锁，数据库并发行为仍需独立验证。

## 账号与请求保护

默认配置：

```dotenv
APP_ORIGIN=http://127.0.0.1:8000
AUTH_COOKIE_SECURE=false
AUTH_ALLOW_REGISTRATION=false
```

浏览器必须使用 APP_ORIGIN 指定的地址；不要混用 localhost 与 127.0.0.1。
APP_ORIGIN 不带末尾斜线。HTTPS 部署必须同时设置 AUTH_COOKIE_SECURE=true。
若需要在本机验证两个账号，主账号初始化完成后，临时开启注册并重启服务，
注册第二个账号、确认隔离后再关闭注册。关闭注册不会禁止已有账号登录。

- 密码采用随机盐及 PBKDF2-HMAC-SHA256（600,000 次）散列；不保存明文密码。
- 会话令牌只放在 HttpOnly、SameSite=Lax Cookie；数据库保存令牌摘要。
- 会话有效期 8 小时，每个账号最多 5 个有效会话；退出会使当前会话失效。
- 写入请求检查来源及 CSRF 校验值，服务端从会话取账号，不接受客户端指定数据归属。
- 每 15 分钟同一来源最多尝试登录 20 次、同一用户名最多 10 次；注册每来源最多 5 次。
  成功登录也计入次数，超过后需等待窗口结束。这里限制的是认证请求，**不是 AI 用量**。
- 反向代理部署还需正确配置可信代理，不能直接信任外部传入的来源 IP 请求头。

手动调用写入接口时也需要当前会话 Cookie、正确的 Origin 和 X-CSRF-Token；
网页会自动处理。Swagger 文档的写入测试若缺少这些信息会返回 403。
会话信息接口不会返回密码或密码散列。

设计参考：[OWASP 密码存储](https://cheatsheetseries.owasp.org/cheatsheets/Password_Storage_Cheat_Sheet.html)、
[OWASP 会话管理](https://cheatsheetseries.owasp.org/cheatsheets/Session_Management_Cheat_Sheet.html)。

## 当前目标

每个账号的首页支持一份独立的当前目标。日期仅记录目标日期，不会自动生成跨天日程。
带入计划时使用目标描述、验收标准和默认时长；可临时修改，只有点击生成才调用 AI。
修改目标不会改写已保存的计划。当前尚未建立目标与历史计划的独立编号关联。
目标保存使用版本检查；其他窗口已更新时会提示重新读取，避免静默覆盖。

## 计划执行进度

历史计划详情显示完成进度，并允许勾选任务或改回未完成。
旧计划无需重新生成：没有执行记录的任务默认未完成。
执行进度按计划单独保存，不修改原始快照，也不自动修改收藏的学习状态。
同一份资料出现在不同计划中时，各自的完成进度独立。
归档资料不影响已经保存的历史计划及其执行记录。
记录和读取进度不调用模型。目前尚未记录实际用时和复盘内容。

## 当前范围

- 当前具备基础账号隔离，仍处于本地验证阶段；完成剩余发布检查前不开放公网。
- 尚无找回密码、修改密码、账号删除或管理员网页；请妥善保存本机初始账号密码。
- AI 接口尚无账号或全站调用限额，费用由配置的 API Key 所属账户承担。
- 新增收藏、保存计划尚无服务端幂等机制。网络超时后可能已写入数据库，先刷新列表或历史确认，再决定是否重试。
- 归档和任务完成使用“设置为指定状态”的更新方式；重复更新状态与重复创建新记录是不同问题。
- 收件箱和归档列表分别加载各自最近最多 100 条记录；收藏搜索和筛选在这 100 条内进行。
- 学习计划使用独立查询，不受收藏页搜索条件影响。
- AI 计划需要点击保存才会进入历史；快速计划目前只在页面展示。
- 归档只影响之后生成的计划；保存过的历史快照不会改写。
- 归档和恢复使用数据库操作，不消耗模型额度。
- 修改收藏状态后，需要重新生成计划。
- Git 保存项目代码，不备份 MySQL 中的收藏数据。
- init.sql 用于初始化；不会自动更新已有表的结构。
